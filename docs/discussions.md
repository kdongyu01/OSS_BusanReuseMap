# GitHub Discussions 운영안

## 카테고리

현재 GitHub 기본 카테고리를 다음 목적에 맞게 사용합니다.

| 카테고리 | 목적 |
|---|---|
| Ideas | RFC와 새로운 기술·데이터 제안 |
| Q&A | 실행 오류와 사용 방법 질문 |
| Announcements | 배포·주요 결정 공지 |
| Show and tell | 분석 결과와 시연 공유 |

## RFC 운영

- 제목에 `RFC:` 접두사를 붙입니다.
- 배경, 제안, 대안, 영향, 질문, SLA를 포함합니다.
- 첫 의견은 7일 이내에 기록합니다.

첫 RFC: [합성 자재 데이터의 공개 범위와 검증 절차](https://github.com/kdongyu01/OSS_BusanReuseMap/discussions/15)
