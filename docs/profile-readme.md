# kdongyu01

## OSS 부산 잔여자재 재사용 지도

부산 센텀시티 일반산업단지의 잔여자재와 필요한 자재를 연결하는 오픈소스 MVP를 개발하고 있습니다.

### 관심 분야

- Python 기반 데이터·AI 개발
- React와 TypeScript 기반 서비스 구현
- GIS·공공데이터 활용
- GitHub Actions와 개발 생산성 자동화

### 학습 목표

- 측정 가능한 CI/CD 파이프라인 설계
- 공개 데이터와 합성 데이터의 안전한 구분
- 작은 단위의 협업·리뷰·문서화 습관 정착
