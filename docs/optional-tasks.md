# 1~8주차 선택과제 현황

| 주차 | 선택과제 | 구현 상태 |
|---|---|---|
| 1 | GitHub Profile README | `docs/profile-readme.md` 작성 후 프로필 저장소에 배포 |
| 2 | JSON Artifact·주간 보고서 | DORA Workflow에서 JSON·HTML·Markdown Artifact 생성 |
| 3 | Cycle Time·Velocity·Burndown | `project-metrics.yml`에서 Milestone 기반 자동 산출 |
| 4 | PR 템플릿·CODEOWNERS·브랜치 보호·협업 문서 | PR 템플릿·문서는 완료, CODEOWNERS와 보호 규칙은 GitHub 설정 적용 |
| 5 | ADR·자동 응답·SLA·Discussions/RFC | ADR·Issue 자동 응답·Project 지표 Workflow 구현, Discussions/RFC는 GitHub 설정 후 운영 |
| 6 | 라이선스 비교·Inner Source 로드맵 | `docs/license-and-innersource.md` 작성 |
