# 데이터 공개 정책

## 현재 상태

실제 기업 잔여자재 데이터는 아직 확보하지 않았습니다. 초기 화면과 테스트에는 합성 데이터를 사용하며, 합성 데이터임을 사용자 화면과 문서에 표시합니다.

## 공개 금지 항목

- 기업명과 담당자 연락처
- 실제 재고 수량과 내부 관리번호
- 보안상 민감한 정확한 위치
- 기관 또는 기업의 비공개 문서
- 공개 이용 조건을 확인하지 않은 외부 데이터

## 데이터 도입 원칙

공개 데이터는 출처, 수집일, 이용 조건, 공간 범위를 기록합니다. 주소를 좌표로 변환할 때는 좌표계와 위치 정확도를 함께 기록하고, 누락·중복 위치를 검증합니다.
