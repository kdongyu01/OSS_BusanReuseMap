# 개인 PR 리뷰 가이드

이 프로젝트는 외부 PR 리뷰어 없이 개인 리뷰 실습으로 4주차 과제를 수행합니다. 따라서 자기 승인을 독립적인 코드 리뷰 성과로 표현하지 않고, 리뷰 절차와 검증 기록을 남기는 데 목적이 있습니다.

## 리뷰 순서

1. PR의 완료 조건과 연결된 Issue를 확인합니다.
2. 변경 파일을 기능 단위로 읽습니다.
3. `MUST`, `SHOULD`, `NIT` 의견을 분리합니다.
4. `npm run build`, 테스트, 화면 확인 결과를 기록합니다.
5. 수정 커밋 후 같은 체크리스트를 다시 확인합니다.

## 리뷰 기준

- 기능이 PR의 목표 범위를 벗어나지 않는가
- 입력 누락과 데이터 없음 상태가 처리되는가
- 개인정보나 기업 기밀이 포함되지 않는가
- 비동기 작업과 API 오류가 사용자에게 설명되는가
- TypeScript 오류와 빌드 오류가 없는가
- 문서와 구현의 기술 스택이 일치하는가
