# Getting Started

## 요구사항

- Node.js LTS
- npm
- Git

## 실행

```bash
npm install
npm run dev
```

## 검증

```bash
npm run build
```

실제 기업 데이터는 저장소에 넣지 않습니다. 현재 데이터가 필요한 기능은 공개 또는 합성 데이터를 사용합니다.
