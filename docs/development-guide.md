# Development Guide

## 브랜치

- `main`: 배포 가능한 상태
- `feature/<작업명>`: 기능 개발
- `fix/<작업명>`: 오류 수정

## 커밋

Conventional Commits 형식을 사용합니다.

- `feat`: 기능 추가
- `fix`: 오류 수정
- `docs`: 문서 변경
- `ci`: 자동화 변경
- `chore`: 설정 변경

## 변경 절차

1. Issue를 선택하고 작업 내용을 확인합니다.
2. Feature 또는 Fix 브랜치를 만듭니다.
3. 작은 단위로 commit합니다.
4. Pull Request를 생성합니다.
5. 개인 리뷰 체크리스트와 빌드 결과를 확인합니다.
6. `main`에 병합합니다.
