# 프로젝트 제안서

## 프로젝트명

부산 산업단지 잔여자재 재사용 지도

저장소명: `OSS_BusanReuseMap`

## 문제 정의

산업단지 기업은 생산·공정 변경 후 남은 자재를 보유하더라도 자재의 종류, 상태, 수량, 보관 위치를 외부에 알리기 어렵습니다. 반대로 다른 기업은 필요한 자재가 주변에 존재하는지 알기 어려워 새 자재를 구매하거나 폐기물 처리 비용을 부담할 수 있습니다.

본 프로젝트는 잔여자재 정보를 표준화하고 지도와 검색 화면으로 보여주어, 자재를 필요로 하는 사용자가 재사용 후보를 빠르게 확인하도록 돕는 MVP를 구현합니다.

## 시범 범위

- 지역: 부산 해운대구 센텀시티 일반산업단지
- 데이터: 초기에는 공개·합성 데이터
- 사용자: 자재를 보유한 기업 담당자, 자재를 찾는 기업 담당자, 산업단지 지원기관
- 범위: 자재 등록, 지도·목록 조회, 조건 기반 후보 매칭

데이터가 충분하지 않으면 다른 부산 산업단지의 공개 데이터를 보조 시범 데이터로 사용할 수 있습니다. 이 경우 화면에서 시범 지역을 구분합니다.

## 핵심 기능 3개

1. 잔여자재 등록: 자재명, 유형, 상태, 수량, 위치, 공개 가능 여부를 입력합니다.
2. 지도·목록 탐색: 자재 유형과 상태를 필터링하고 위치를 확인합니다.
3. 재사용 후보 매칭: 필요한 자재의 조건과 잔여자재 속성을 비교해 후보와 점수를 보여줍니다.

## 기술 스택

- React + TypeScript + Vite: 단일 개발자가 빠르게 구현하고 정적 배포하기 위한 사용자 화면
- GitHub Pages: 1~7주차 CI/CD와 Deployment 기록을 함께 검증하기 위한 배포 대상
- Python + Pandas/GeoPandas: 후속 데이터 정제와 GeoJSON 생성
- MapLibre GL JS: 후속 지도 화면
- GitHub Actions: Lint, Test, Build, 배포, DORA 기록 수집

초기 MVP에는 로그인, 별도 API 서버, 데이터베이스, 유료 AI API를 필수로 포함하지 않습니다.

## 성공 판단

기능 구현과 문제 해결 효과를 분리합니다. 초기 목표는 “자재 후보를 지도와 목록으로 확인하고 조건으로 좁힐 수 있는가”를 검증하는 것입니다. 실제 재사용량이나 비용 절감 효과는 현장 데이터와 사용자 평가 전까지 성과로 주장하지 않습니다.
